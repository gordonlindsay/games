# The Wedding Crashers

A race to the cake. Play as Heath or Sam: nick the sweets, dodge the drunk uncles, aunties and grannies,
and beat the other one to the cake. One stick to run, with Jump and Dash buttons.

**Play:** https://gordonlindsay.github.io/weddingcrashers/

`index.html` is the whole game. It was first a claude.ai artifact
(https://claude.ai/artifact/SS4x4MfRYxAWc9P93oGe8Y). This repo starts from that page as it was published on
2026-09-26 and is the source from here on.

## Preview and release

- **Preview:** run `python3 -m http.server 3062` in this folder and open http://localhost:3062/.
- **Release:** push to `main`. GitHub Pages redeploys in about a minute.
