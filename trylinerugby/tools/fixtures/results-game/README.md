# results-game fixtures

`results.json` is a results file (version 1, `trylinerugby/docs/results-schema.md` on the data side) for `tools/results-game.mjs`
and its screenshots. Only Farnham's result and table line are real: its 1st XV won 38-34 away at Old Alleynians on Sat 14 Nov 2026, 5th of 12 with
16 points after P7 W4 D0 L3 (Pitchero, sampled 15 Nov 2026). Its places before the match, and every other entry, are made up for the
tests, in the file's shape.
