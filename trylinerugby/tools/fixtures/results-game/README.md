# results-game fixtures

`results.json` is a results file (version 1, `trylinerugby/docs/results-schema.md` on the data side) for `tools/results-game.mjs`
and its screenshots. Only Farnham's entry is real, exactly as the weekly job wrote it on 15 Nov 2026: its 1st XV won 38-34 away at Old Alleynians on
Sat 14 Nov, 5th of 12 with 16 points after P7 W4 D0 L3, 6th before the match against 8th, so a win and Form +1. England's men's 78-15
win over Japan is real too (Form +2). Every other entry (Wimbledon's loss, Old Alleynians', Northampton's draw, Japan's, England
Women's) is made up for the tests, in the file's shape, so that a loss (Form −1), a draw and a women's Test are covered.
